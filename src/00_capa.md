# Material da Disciplina DS143 - Estruturas de Dados II

Disciplina obrigatória do 4º período do TADS, com 30 horas. Estuda estruturas de
dados avançadas, árvores, tabelas de dispersão e grafos, e os algoritmos
associados a elas.

A partir de 2026/2 o material é escrito em **Go**. As páginas reunidas em
"Material anterior" ainda estão em C e vão sendo convertidas ao longo do
semestre.

Use a barra lateral para navegar. O ícone de impressora, no alto à direita,
gera uma versão de página única com todo o conteúdo, útil para estudo antes das
provas.
